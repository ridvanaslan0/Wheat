# Changelog

## 1.0.0

- Type directly in the mascot's speech bubble; the chat window is now optional.
- Runs as administrator (one UAC prompt at launch).
- "Start with Windows" option using an elevated scheduled task (no UAC prompt at login).
- One-time permission at first launch; no per-action confirmations by default
  (optional "Ask for confirmation before every action" setting).
- New `run_powershell` tool.
- Single self-contained `Wheat.exe` build.
- Whole project translated to English.
